# Far Gallery — Implementation Status

## Implemented
- **Photos & Timeline (`feature/gallery`, `core/media`)**: MediaStore + Paging 3 timeline with `Years / Months / Days / All` segmented control, Photos / Videos / Favorites filter chips, two-finger pinch to adjust 2–6 grid columns, multi-select action bar (Share, Add to Album, System Trash), access status badge (`Full access` / `Selected photos` / `No access`), and shared-element transitions.
- **Glass UI Design System (`ui/theme`, `ui/glass`, `ui/nav`, `ui/feedback`, `ui/brand`)**: Frosted backdrop blur via Haze (`RenderEffect` blur on API 31+, 94–96% opaque tint fallback when reduced transparency or API 30), floating `GlassBottomBar` pill + detached Camera button on phones (`< 600dp`), `GlassNavRail` on wide screens (`>= 600dp`), Light / Dark / AMOLED modes, curated accent swatches, Material You toggle, bundled fonts (`Space Grotesk`, `Plus Jakarta Sans`, `JetBrains Mono`), and English / Urdu RTL localization.
- **Viewer, Video & Non-Destructive Editor (`feature/viewer`, `feature/video`, `feature/editor`)**: Swipeable pager, pinch + double-tap zoom up to 6x, pan while zoomed, swipe-down dismiss, thumbnail strip, EXIF/path details bottom sheet, local Room Tags CRUD, on-device ML Kit OCR scan & copy, Media3 `ExoPlayer` with speed & multi-audio track selection, ±10s seek, `FrameGrabber`, `VideoTrimmer` (Media3 `Transformer`), Picture-in-Picture, and Photo Editor (`Brightness / Contrast / Saturation / Warmth`, crop presets, rotate/flip, Hold-to-Compare, undo/redo, high-res copy save + `EditRecipe` persistence).
- **Albums, Memories, Search, Duplicates & Excluded Folders (`feature/albums`, `feature/duplicates`)**: Room-backed Albums (create, rename, pin/unpin, delete grouping only without deleting files), Memories (`MemoryRules.onThisDay` & recent highlights), Collections (`Favorites`, `Videos`, `Screenshots`, `Camera`, `Duplicates`, `Recently Deleted` with restore, `Excluded Folders` with explicit non-security notice), Search combining filename, local Tags, and on-device OCR index, plus exact SHA-256 `DuplicateFinder`.
- **Camera (`feature/camera`, `CameraActivity`)**: CameraX `LifecycleCameraController`, real hardware capability queries (`CameraInfo` zoom stops, flash, EV range, front camera), Timer (0/3/5/10s), 1:1 Square / 4:3 Photo / Video modes, tap-to-focus + vertical EV drag, rule-of-thirds grid, gravity-sensor horizon `LevelIndicator`, bundled ML Kit QR/barcode scanner, volume-key shutter, `ON_STOP` recording finalization, and capture-for-result intents (`IMAGE_CAPTURE`, `VIDEO_CAPTURE`, `STILL_IMAGE_CAMERA`, `VIDEO_CAMERA`).
- **Files (`feature/files`, `core/storage`)**: Adaptive Apple-Files phone layout and `>= 840dp` desktop multi-pane sidebar/pathbar layout, persistable SAF folder grants (`OpenDocumentTree`), Starred files, Copy/Move/Paste with size verification & `Collision.Rename`, Rename/Delete/New Folder, Safe ZIP extraction (`SafeZip` traversal & ratio bomb guards), `PdfRenderer` and 256 KB Text previews.
- **Offline Privacy & Resilience**: Zero `INTERNET` permission, zero private vault (completely removed), crash-loop safe mode after 3 startup crashes, privacy-safe `last_crash.txt`, and Room `OperationRecord` interruption recovery.

## Verification
- Verified with Kotlin compilation (`compile_applet`) and Robolectric unit tests (`gradle :app:testDebugUnitTest`).
- Camera preview/recording, SAF external SD providers, Media3 hardware decoders, and OEM default-app chooser flows require physical device verification.
